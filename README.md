# 🌿 The Forest

**Living Ecosystem Website**

## Tech Stack
- Frontend: Vanilla HTML + CSS + Canvas (P5.js-style animations)
- Backend: Node.js + Express + WebSocket
- Port: Backend 3001 | Frontend: open index.html

## Run
```bash
cd backend && npm install && npm start
cd frontend && open index.html
```
